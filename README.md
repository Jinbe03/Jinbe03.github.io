# Bruno R. Maldonado — Interactive Software Engineer Portfolio

Interactive **Subway Station × Manga UI** Software Engineer portfolio hosted live on **GitHub Pages**:  
**Live Site:** https://jinbe03.github.io/

Built with **zero frameworks and zero build steps** — pure HTML5, CSS3, vanilla ES6 JavaScript, custom original artwork, and a procedural Web Audio API sound engine.

---

## Key Features (`v2.0.0`)

- **3D Perspective Station & Express Train Rig:** Dynamic camera shifts across three custom environments (underground platform, speeding express car interior, and night skyline concourse) with spring-damped mouse parallax and a 3D track-aligned passing train consist.
- **Curved Pause Menu + 6 Bespoke Section Skins:**
  1. **Profile:** Status identity plate + live SVG engineering attributes pentagon radar.
  2. **Experience:** `MISSION CLEARED` report clipboard with impact medal cards.
  3. **Projects:** Interactive Compendium Build Deck featuring live production deploys and backend/AI projects.
  4. **Skills:** Asymmetric combat loadout slots across Backend & Data, Frontend & Mobile, and Cloud & DevOps.
  5. **Certs & Education:** 6 custom woodcut **Tarot Arcana (`I–VI`)** cards linked to **6 verifiable INACAP official PDF certificates** (`900 hrs` total), inspectable directly inside the in-page PDF viewer modal.
  6. **Contact:** Interactive **SNS Smartphone** composited inside a custom manga-inked hand overlay with one-click copy email, mailto, LinkedIn, and in-page resume inspection.
- **Smooth Navigation UX:**
  - Dramatic paper-crumple & cut-in wipe reserved for entering/exiting the Title Screen.
  - Instant directional vertical scroll-glide between sections via curved menu clicks, keyboard (`↑`/`↓`, `W`/`S`, `1–6`, `Esc`), or desktop mouse wheel.
- **Trilingual + Dynamic Language-Aware Resume PDFs:**
  - Seamless **`EN / ES`** toggle + hidden **Japanese (`日本語 ★`)** mode.
  - Single smart Resume/CV HUD button that dynamically opens the matching PDF (`EN`, `ES`, or secret `JP` edition) inside the in-page viewer without leaving the page.
- **Original Web Audio API Engine (`100% Procedural, Zero Copyrighted Audio`):**
  - Toggleable **`♪ BGM`** (122 BPM Nu-Jazz House groove) and **`SFX`** (layered Foley clicks, snaps, cancels, and dialogue micro-ticks).
  - Secret interactive Easter Eggs (3-phase *All-Out Attack* sequence with 134 BPM Hip-Hop Brass synth groove, *Calling Card* ransom-letter generator with stealth heist loop, and secret Japanese mode with Hyoshigi/Shamisen sting + Japanese CV PDF).
- **Full Multi-Screen Responsive Layout:**
  - Verified across 4K/1920px monitors, compact 1366×768 / 1280×720 laptops, tablets, and mobile phones down to `320px–375px` (with a compact `3×2` mobile station grid and full-width mobile SNS screen).
